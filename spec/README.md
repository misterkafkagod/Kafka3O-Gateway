# Specs

The specs for the whole Kafka3O solution (UI + gateways) live in the **Kafka3O-UI** repository, under `spec/`:

- `ROADMAP.md` — vision, features, milestones, learnings
- `FUNC-SPEC.md` — behaviors and acceptance criteria
- `TECH-SPEC.md` — stack, conventions, structure and testing for both the gateway and the UI
- `phases/` — phase plans
- `discovery/` — discovery notes

Edit them there, not here.
